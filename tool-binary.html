Pairwise: binary outcomes

Risk and odds ratios for events such as complications or mortality.

1

What it is

Every patient in every trial answers the same yes-or-no question: did the event happen? Inside one trial, that gives a simple 2×2 table, with events and non-events in each arm.

Each table is turned into one number that compares the arms, most often the risk ratio: the risk with the intervention divided by the risk with the control. The meta-analysis then combines these numbers across trials, giving more weight to larger and more informative trials.

The result is one pooled effect with its 95% confidence interval, and a measure of how much the trials disagree with each other (heterogeneity).

Worked exampleOne trial, step by step
EventNo eventRisk
Intervention128812%
Control208020%
RR = 12% ÷ 20% = 0.6040% lower risk with the interventionRD = 12% − 20% = −8 pointsabout 1 event avoided per 13 patients treated

Repeat for every trial, then pool: that is the meta-analysis.

2

When to use it

Use it when

  • The outcome is an event that either happens or does not: complication, transfusion, recurrence, mortality, conversion to open surgery.
  • You are comparing two groups, such as a new technique against the standard one.
  • Each study reports how many patients had the event, and how many patients there were, in each group.

Choose another tool when

  • The outcome is a measurement (minutes, days, a score): use continuous outcomes.
  • Follow-up time differs a lot between patients and timing matters, as in survival: use time-to-event methods.
  • There is no comparison group, only case series: use single-arm binary outcomes.

The template, parameter by parameter

m <- metabin(event.e = ev_int, n.e = n_int,
             event.c = ev_ctl, n.c = n_ctl,
             studlab = study, data = dat,
              = "RR",
              = "MH",
              = "REML",
              = 0.5,  = "only0",
              = FALSE,
              = FALSE,  = TRUE,
              = FALSE,
             label.e = "Intervention", label.c = "Control")

m <- update(m,
             = if (m$tau2 > 0) "HK" else "classic")

In my work

Figures from my published reviews, next to the metabin() call behind them. These analyses used the Wald confidence interval: when they were done, Cochrane had not yet recommended switching to Hartung-Knapp when tau² > 0. Click a figure to enlarge it.

Need for red blood cell transfusionRisk ratio, 14 trials. From JAMA Surg, 2026 ↗
m <- metabin(
  e.e, n.e, e.c, n.c,           # events/totals per arm
  data = dat,                   # one row per study
  studlab = Study,              # study names
  sm = "RR",                    # risk ratio
  method = "MH",                # Mantel-Haenszel
  method.tau = "DL",            # DerSimonian-Laird tau²
  method.random.ci = "classic"  # Wald CI
)
